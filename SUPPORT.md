# Getting support

## Read first

- [README.md](README.md): what exists today, how to build it, and what
  is not available yet.
- Generator behaviour (what a password type produces, its entropy) is
  documented in [jspassgen](https://github.com/sebastienrousseau/jspassgen).

## Questions and bugs

Open an [issue](https://github.com/sebastienrousseau/jspassgen-sdk-java/issues/new)
with the version, your Java version, a minimal reproducer and the
exception message. Never paste real passwords, keys or tokens.

## Security

Do not open a public issue. Follow [SECURITY.md](SECURITY.md).

## Supported versions

| Version | Supported | Notes |
| :--- | :--- | :--- |
| 0.0.24 | Yes | Latest release; random source only |
| 0.0.23 | No | Superseded by 0.0.24 |
| 0.0.22 | No | Superseded by 0.0.23 |

Only the latest `0.0.x` gets fixes while the project is pre-1.0. Support
is best effort by a single maintainer ([GOVERNANCE.md](GOVERNANCE.md)).
